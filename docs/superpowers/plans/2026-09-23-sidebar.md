# Implementation Plan: Sidebar 组件（对齐 gpui-kit）

**Goal:** 把 `gpui-kit/crates/component/src/sidebar`（mod/menu/group/header/footer 五个文件）完整移植到
`iced-kit` 的 `src/widgets/sidebar.rs`，API 形态一一对应，行为差异仅来自 iced 的无状态约定。
产出：7 个颜色 token、`Sidebar`/`SidebarGroup`/`SidebarMenu`/`SidebarMenuItem`/`SidebarHeader`/
`SidebarFooter`/`SidebarToggleButton` 七个组件、私有宽度过渡 widget `SidebarShell`、
`SidebarLayout` 纯函数 + 10 个布局单测、3 个渲染快照、gallery 演示区、README/THEMING/spec 文档回写。

**Architecture:** 单文件 `src/widgets/sidebar.rs`。容器状态全部由调用方持有（`collapsed`、
`active`、子菜单 `open`），组件经消息回调上报意图（`on_select`/`on_toggle`/`on_press`）。
子节点用 `Box<dyn FnOnce(bool) -> Element>` 存储以支持异构 children；`SidebarItem` trait 简化为
`into_element(self, collapsed: bool)`。宽度动画由私有 `SidebarShell` 实现：tree state 存
`SpringState`，`layout` 按当前插值宽度给节点、内容按自身目标宽度布局，`draw` 用 `with_layer`
裁剪，裁剪区外的事件光标降为 `Cursor::Unavailable`；宽度收到 0 时跳过 layout/draw/update/overlay，
替代 gpui-kit 的 `finish_hide` 定时器。模式判定移植为纯函数 `SidebarLayout`。

**Tech Stack:** Rust、iced 0.14.0（`iced::advanced::Widget`、raw `iced::widget::button`、
`MouseArea::on_right_press`、`tooltip_at`、`overlay::Layer`）、crate 自有的
`motion::{Spring, SpringState, DURATION_NORMAL, reduce_motion}`、`iced_test::Simulator` 快照。

### 2. 与 spec 的细节偏差清单

1. **`.context_menu(builder)` → `.context_menu(Message)`**：菜单项右键只发一个意图消息，
   应用在 `update` 里经 `overlay::Layer::dropdown(...)` 挂 `ContextMenu::new(items, at)`。
   `MouseArea::on_right_press` 已确认存在（`mouse_area.rs:68`）。
2. **折叠 tooltip**：`tooltip_at(content, label, TooltipPosition::Right)`（仅在
   `collapsed && icon.is_some()` 时挂）。
3. **行体点击消息策略**：一次 press 只发一个消息——`disabled` 什么都不发；有 `on_select`
   发 `on_select`；否则有 `on_toggle` 发 `on_toggle`。caret 是嵌套的 raw
   `iced::widget::button`，独立发 `on_toggle`（iced button 先转发子事件再查
   `shell.is_event_captured()`，`button.rs:297`，嵌套可行）。
4. **子菜单 caret 图标**：`ChevronDown`（开）/`ChevronRight`（关），先例
   `navigation.rs:80-85`（`Icon::new(...).into_element(Size::Md)`）。
5. **Header/Footer**：设 `.on_press` 时用 raw button + `button::StyleFn` class 包裹
   （获得 hover/press）；未设时是静态容器（仅 `selected` 高亮，无 hover）——这是
   documented deviation，gpui-kit 的 hover 在无 press 语义的 div 上也能触发，iced 侧
   样式必须来自 widget status。行内布局用「非末子包 `container().width(Fill)`」近似
   gpui 的 `justify_between`（仓库无 `justify_between` 用例）。
6. **单侧 1px 边框**：`iced::Border` 四边宽度统一、无分边 API，用 1px 宽、fill 高、
   背景 `sidebar_border` 的 `container` 作 edge 行，左栏放右、右栏放左。
7. **Header/Footer 折叠 padding**：gpui footer 折叠分支疑似笔误（`pt_2 px_2`），
   按 `pb_2 px_2` 移植并在此注明。
8. **`.disable(bool)` → `.disabled(bool)`**：跟随仓库既有命名（`Button::disabled`）。
9. **内容树每帧构建、offcanvas/Icon 中间帧的透明 gap**：与 gpui-kit 一致/可接受的简化，
   不做虚拟化（gpui 用 `ListState` 虚拟滚动，iced 端侧栏条目数量级小，直接全量构建）。
10. **折叠态首尾留白**：gpui-kit 在折叠时对首个/末个分组 item 额外叠加 `pt_3`/`pb_3`
    （容器 `p_2` + item `pt_3` = 20px），iced 端统一为容器 padding 8px——保留展开态
    12px 的等效视觉，折叠态首尾各少 12px 留白，视为取舍。
11. **长标签不裁剪**：gpui-kit `overflow_x_hidden` 会裁掉超长标签，iced 端 label 不裁剪
    （文本直接溢出）。侧栏标签普遍较短，不为此引入额外裁剪层。

### 3. 关键实现依据（已核对源码）

- `Node::with_children(size, children)` 子节点起于 (0,0)，`move_to` 是相对父节点的偏移
  （`iced_core-0.14.0/src/layout/node.rs`，`Node::container` 先例）→ `SidebarShell` 用
  `Node::with_children(Size::new(current_w, h), vec![content.move_to(Point::new(offset, 0.0))])`；
  `align_end` 时 `offset = current - content_width`（可为负，滑出后被 `with_layer` 裁掉）。
- raw button 事件先转发子 widget、`shell.is_event_captured()` 短路（`button.rs:297`）→
  嵌套 caret button 可行；`button::Status` 只使用 `Active`/`Hovered` 两个变体
  （`list.rs::row_style` 先例）。
- `TabStrip`（`tabs.rs:127-374`）是 `SidebarShell` 的仿写模板：`update` 里 prime、
  每帧 `SpringState::step`、未 settle 时 `shell.request_redraw()`。注意 TabStrip 自身节点
  宽度不变所以只 redraw；`SidebarShell` 的节点宽度每帧都变，未 settle 时还必须
  `shell.invalidate_layout()`（`iced_core-0.14.0/src/shell.rs:128` 确有此方法），否则
  运行时可能复用旧布局、动画卡在第一帧。
- 快照测试在 `reduce_motion()` 下取稳定终态；`SidebarShell` 首帧 prime 到 target，
  保证快照第一帧就是终态。
- `assert_renders` 首次运行写出参考 PNG；故意变更需删旧文件重跑。

### 4. 参考实现的移植范围

- `mod.rs`：`SidebarLayout`/`SidebarWrapperLayout`/常量/`SidebarCollapsible` → 纯函数与
  枚举；`Sidebar` 容器 → builder + `into_element`；`SidebarToggleButton` → kit Button 组合。
  gpui 的 `SidebarAnimationState`（定时器 hide）→ `SidebarShell` 宽度归零跳过。
  10 个 `SidebarLayout` 单测逐个移植（`px()` → `f32` 字面量）；`animation_id` 测试不移植
  （ElementId 动画注册表是 gpui 概念，iced 侧 tree state 天然按实例隔离）；
  5 个 `SidebarAnimationState` 测试改写为 `ShellState` 语义测试。
- `menu.rs`：`SidebarMenu`（`v_flex gap_2` → `column spacing 8`）、`SidebarMenuItem`
  （嵌套子菜单 `ml_3.5 pl_2.5 py_0.5` + 1px 左边线 + `gap_1`、active/disabled/suffix/
  折叠 tooltip/右键菜单）。
- `group.rs`：分组标题（`px_2 h_8 text_xs fg@0.7`，Icon 折叠时隐藏），children `gap_2`。
- `header.rs`/`footer.rs`：`h_flex gap_2 p_2 w_full justify_between rounded`，
  selected/hover → `sidebar_accent` 背景 + `sidebar_accent_foreground` 文字。

- [ ] **2.2 绿：实现枚举与纯函数**。`sidebar.rs` 模块注释之后、测试之前追加：

  ```rust
  /// The default width of an expanded sidebar, in logical pixels.
  pub const DEFAULT_WIDTH: f32 = 255.0;

  /// The width of a sidebar collapsed to its icons, in logical pixels.
  pub const COLLAPSED_WIDTH: f32 = 48.0;

  /// How a [`Sidebar`] behaves when it is collapsed.
  ///
  /// Mirrors `gpui-kit`'s `SidebarCollapsible`; `From<bool>` keeps the old
  /// shorthand working (`true` = [`Self::Icon`], `false` = [`Self::None`]).
  #[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
  pub enum SidebarCollapsible {
      /// Collapse to an icon rail at [`COLLAPSED_WIDTH`] (shadcn's `icon` mode).
      #[default]
      Icon,
      /// Slide out of the layout entirely (shadcn's `offcanvas` mode).
      Offcanvas,
      /// Never collapse; the `collapsed` flag is ignored.
      None,
  }

  impl From<bool> for SidebarCollapsible {
      fn from(collapsible: bool) -> Self {
          if collapsible {
              Self::Icon
          } else {
              Self::None
          }
      }
  }

  /// Which edge a [`Sidebar`] sits on.
  #[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
  pub enum SidebarSide {
      /// The leading edge (the default).
      #[default]
      Left,
      /// The trailing edge.
      Right,
  }

  impl SidebarSide {
      /// Whether the sidebar is anchored to the left edge.
      #[must_use]
      pub const fn is_left(self) -> bool {
          matches!(self, Self::Left)
      }

      /// Whether the sidebar is anchored to the right edge.
      #[must_use]
      pub const fn is_right(self) -> bool {
          matches!(self, Self::Right)
      }
  }

  /// What wraps the sidebar: nothing, a fixed-width clip, or a width transition.
  #[derive(Clone, Copy, Debug, PartialEq)]
  enum SidebarWrapperLayout {
      None,
      Static { width: f32 },
      Animated { target_width: f32 },
  }

  /// The layout consequences of a sidebar's mode — a straight port of
  /// `gpui-kit`'s `SidebarLayout`, so the mode table stays testable without
  /// rendering anything.
  #[derive(Clone, Copy, Debug, PartialEq)]
  struct SidebarLayout {
      icon_collapsed: bool,
      offcanvas_collapsed: bool,
      align_child_to_end: bool,
      wrapper: SidebarWrapperLayout,
  }

  impl SidebarLayout {
      fn new(
          collapsible: SidebarCollapsible,
          collapsed: bool,
          expanded_width: Option<f32>,
          side: SidebarSide,
      ) -> Self {
          let collapsed = collapsed && collapsible != SidebarCollapsible::None;
          let wrapper = match collapsible {
              SidebarCollapsible::None => SidebarWrapperLayout::None,
              SidebarCollapsible::Icon => match expanded_width {
                  Some(expanded_width) => SidebarWrapperLayout::Animated {
                      target_width: if collapsed {
                          COLLAPSED_WIDTH
                      } else {
                          expanded_width
                      },
                  },
                  None => SidebarWrapperLayout::None,
              },
              SidebarCollapsible::Offcanvas => match (expanded_width, collapsed) {
                  (Some(_), true) => SidebarWrapperLayout::Animated {
                      target_width: 0.0,
                  },
                  (Some(expanded_width), false) => SidebarWrapperLayout::Animated {
                      target_width: expanded_width,

                  (None, true) => SidebarWrapperLayout::Static { width: 0.0 },
                  (None, false) => SidebarWrapperLayout::None,
              },

          // edge); every other case keeps its child anchored to the side it
          // is leaving, so the shrinking clip eats it from the outer edge.
          let align_child_to_end = match collapsible {
              SidebarCollapsible::Offcanvas => side.is_left(),
              _ => side.is_right(),
          };

          Self {
              icon_collapsed: collapsed && collapsible == SidebarCollapsible::Icon,
              offcanvas_collapsed: collapsed && collapsible == SidebarCollapsible::Offcanvas,
              align_child_to_end,
              wrapper,
          }
      }
  }
  ```

  ```rust
  ///
  /// `gpui-kit` pushes `collapsed` down through a `Collapsible` trait with a
  /// getter and a setter; stateless iced only needs the render half, so the
  /// collapsed flag arrives as an argument.
  pub trait SidebarItem<'a, Message>: Sized {
      /// Renders the item, given whether the sidebar is collapsed to icons.
      fn into_element(self, collapsed: bool) -> Element<'a, Message, Theme>;
  }

  /// A child stored by a [`Sidebar`] or [`SidebarGroup`]: the trait method,
  /// boxed. Boxing — rather than one generic `E` parameter — is what lets a
  /// group hold a menu, a plain item and a nested group at the same time.
  type ItemFn<'a, Message> = Box<dyn FnOnce(bool) -> Element<'a, Message, Theme> + 'a>;

  fn boxed<'a, Message, Item>(item: Item) -> ItemFn<'a, Message>
  where
      Item: SidebarItem<'a, Message> + 'a,
  {
      Box::new(move |collapsed| item.into_element(collapsed))
  }

  /// A vertical run of [`SidebarMenuItem`]s.
  #[must_use = "a SidebarMenu does nothing unless it is given to a Sidebar"]
  pub struct SidebarMenu<'a, Message> {
      items: Vec<SidebarMenuItem<'a, Message>>,
  }

  impl<'a, Message: Clone + 'a> SidebarMenu<'a, Message> {
      /// Creates an empty menu.
      #[must_use]
      pub fn new() -> Self {
          Self {
              items: Vec::new(),
          }
      }

      /// Appends one item.
      #[must_use]
      pub fn child(mut self, child: SidebarMenuItem<'a, Message>) -> Self {
          self.items.push(child);
          self
      }

      /// Appends several items.
      #[must_use]
      pub fn children(
          mut self,
          children: impl IntoIterator<Item = SidebarMenuItem<'a, Message>>,
      ) -> Self {
          self.items.extend(children);
          self
      }
  }

  impl<'a, Message: Clone + 'a> Default for SidebarMenu<'a, Message> {
      fn default() -> Self {
          Self::new()
      }
  }

  impl<'a, Message: Clone + 'a> SidebarItem<'a, Message> for SidebarMenu<'a, Message> {
      fn into_element(self, collapsed: bool) -> Element<'a, Message, Theme> {
          // gpui-kit's menu is a `v_flex` with `gap_2`.
          let mut menu = column![].spacing(8).width(Length::Fill);
          for item in self.items {
              menu = menu.push(item.into_element(collapsed));
          }
          menu.into()
      }
  }

  /// A labelled run of sidebar children.
  #[must_use = "a SidebarGroup does nothing unless it is given to a Sidebar"]
  pub struct SidebarGroup<'a, Message> {
      label: String,
      children: Vec<ItemFn<'a, Message>>,
  }

  impl<'a, Message: Clone + 'a> SidebarGroup<'a, Message> {
      /// Creates a group with a section label.
      #[must_use]
      pub fn new(label: impl Into<String>) -> Self {
          Self {
              label: label.into(),
              children: Vec::new(),
          }
      }

      /// Appends any sidebar child: a menu, an item, a nested group.
      #[must_use]
      pub fn child(mut self, child: impl SidebarItem<'a, Message> + 'a) -> Self {
          self.children.push(boxed(child));
          self
      }

      /// Appends several children.
      #[must_use]
      pub fn children(
          mut self,
          children: impl IntoIterator<Item = impl SidebarItem<'a, Message> + 'a>,
      ) -> Self {
          for child in children {
              self.children.push(boxed(child));
          }
          self
      }
  }

  impl<'a, Message: Clone + 'a> Default for SidebarGroup<'a, Message> {
      fn default() -> Self {
          Self::new("")
      }
  }

  impl<'a, Message: Clone + 'a> SidebarItem<'a, Message> for SidebarGroup<'a, Message> {
      fn into_element(self, collapsed: bool) -> Element<'a, Message, Theme> {
          // gpui-kit's group: `px_2 h_8 text_xs fg@0.7` label, hidden while
          // the sidebar is an icon rail, then children with `gap_2`.
          let mut group = column![].spacing(8).width(Length::Fill);

          if !collapsed {
              let label_style = Size::Xs.text();
              let label = text(self.label)
                  .size(label_style.size)
                  .line_height(label_style.line_height())
                  .class(Box::new(|theme: &Theme| text::Style {
                      color: Some({
                          let foreground = theme.colors().sidebar_foreground;
                          iced::Color {
                              a: 0.7,
                              ..foreground
                          }
                      }),
                  }) as text::StyleFn<'a, Theme>);

              group = group.push(
                  container(label)
                      .width(Length::Fill)
                      .height(Length::Fixed(32.0))
                      .padding(iced::Padding {
                          top: 0.0,
                          right: 8.0,
                          bottom: 0.0,
                          left: 8.0,
                      })
                      .center_y(Length::Fixed(32.0)),
              );
          }

          for child in self.children {
              group = group.push(child(collapsed));
          }

          group.into()
      }
  }
  ```

  ```rust
  #[must_use = "a SidebarMenuItem does nothing unless it is given to a menu"]
  pub struct SidebarMenuItem<'a, Message> {
      label: String,
      icon: Option<IconName>,
      active: bool,
      disabled: bool,
      open: bool,
      on_select: Option<Message>,
      on_toggle: Option<Message>,
      children: Vec<SidebarMenuItem<'a, Message>>,
      suffix: Option<Element<'a, Message, Theme>>,
      context_menu: Option<Message>,
      tooltip_text: Option<String>,
  }

  /// Which way a submenu caret points — the two lucide glyphs, kept apart so
  /// the mapping is unit-testable.
  #[derive(Clone, Copy, Debug, PartialEq, Eq)]
  struct SubmenuCaret {
      down: bool,
  }

  impl SubmenuCaret {
      const fn new(open: bool) -> Self {
          Self { down: open }
      }

      const fn is_down(self) -> bool {
          self.down
      }
  }

  const fn submenu_caret(open: bool) -> SubmenuCaret {
      SubmenuCaret::new(open)
  }

  fn caret_icon(open: bool) -> IconName {
      if open {
          IconName::ChevronDown
      } else {
          IconName::ChevronRight
      }
  }

  impl<'a, Message: Clone + 'a> SidebarMenuItem<'a, Message> {
      /// Creates an item with a label.
      #[must_use]
      pub fn new(label: impl Into<String>) -> Self {
          Self {
              label: label.into(),
              icon: None,
              active: false,
              disabled: false,
              open: false,
              on_select: None,
              on_toggle: None,
              children: Vec::new(),
              suffix: None,
              context_menu: None,
              tooltip_text: None,
          }
      }

      /// Sets the leading icon, shown in both expanded and collapsed states.
      #[must_use]
      pub fn icon(mut self, icon: impl Into<IconName>) -> Self {
          self.icon = Some(icon.into());
          self
      }

      /// Marks the item as the current selection.
      #[must_use]
      pub fn active(mut self, active: bool) -> Self {
          self.active = active;
          self
      }

      /// Greys the item out and silences every message it could send.
      #[must_use]
      pub fn disabled(mut self, disabled: bool) -> Self {
          self.disabled = disabled;
          self
      }

      /// Sets whether a nested submenu is open.
      #[must_use]
      pub fn open(mut self, open: bool) -> Self {
          self.open = open;
          self
      }

      /// Publishes `message` when the row is pressed (selection wins over
      /// toggling — see [`SidebarMenuItem::pressed_message`]).
      #[must_use]
      pub fn on_select(mut self, message: Message) -> Self {
          self.on_select = Some(message);
          self
      }

      /// Publishes `message` when there is nothing to select: a plain submenu
      /// parent collapses/expands through it.
      #[must_use]
      pub fn on_toggle(mut self, message: Message) -> Self {
          self.on_toggle = Some(message);
          self
      }

      /// Nests another item beneath this one, turning the row into a submenu.
      #[must_use]
      pub fn child(mut self, child: impl Into<SidebarMenuItem<'a, Message>>) -> Self {
          self.children.push(child.into());
          self
      }

      /// Nests several items beneath this one.
      #[must_use]
      pub fn children(
          mut self,
          children: impl IntoIterator<Item = impl Into<SidebarMenuItem<'a, Message>>>,
      ) -> Self {
          for child in children {
              self.children.push(child.into());
          }
          self
      }

      /// Sets the trailing element (a badge, a shortcut hint).
      #[must_use]
      pub fn suffix(mut self, suffix: impl Into<Element<'a, Message, Theme>>) -> Self {
          self.suffix = Some(suffix.into());
          self
      }

      /// Asks the application for a right-click menu at the pointer: the item
      /// only publishes the intent, the overlay is mounted by the update.
      #[must_use]
      pub fn context_menu(mut self, message: Message) -> Self {
          self.context_menu = Some(message);
          self
      }

      /// Overrides the tooltip label shown while the sidebar is an icon rail.
      #[must_use]
      pub fn tooltip_text(mut self, tooltip: impl Into<String>) -> Self {
          self.tooltip_text = Some(tooltip.into());
          self
      }

      /// The tooltip shown while collapsed: the label, or the override — but
      /// only for items that still have an icon to hover.
      fn collapsed_tooltip(&self, collapsed: bool) -> Option<String> {
          (collapsed && self.icon.is_some()).then(|| {
              self.tooltip_text
                  .clone()
                  .unwrap_or_else(|| self.label.clone())
          })
      }

      /// What the row's press publishes — at most one message: selecting
      /// wins, and a submenu without a selection falls back to toggling.
      /// Emitting both would belong to the application's `update`, which owns
      /// both flags anyway.
      fn pressed_message(&self) -> Option<Message> {
          if self.disabled {
              return None;
          }
          self.on_select.clone().or_else(|| self.on_toggle.clone())
      }
  }

  /// The hover/active/disabled skin of one row.
  fn item_style(
      theme: &Theme,
      status: button::Status,
      active: bool,
      disabled: bool,
  ) -> button::Style {
      let colors = theme.colors();
      let hovered = !active && !disabled && matches!(status, button::Status::Hovered);

      button::Style {
          background: if active {
              Some(Background::Color(colors.sidebar_accent))
          } else if hovered {
              Some(Background::Color(iced::Color {
                  a: 0.8,

          } else {
              None

          text_color: if active || hovered {
              colors.sidebar_accent_foreground
          } else if disabled {
              colors.muted_foreground
          } else {
              colors.sidebar_foreground
          },
          border: Border {
              radius: f32::from(theme.radius().md).into(),
              ..Border::default()
          },
          ..button::Style::default()
      }
  }

  fn caret_style(theme: &Theme, status: button::Status, disabled: bool) -> button::Style {

      button::Style {

  impl<'a, Message: Clone + 'a> SidebarItem<'a, Message> for SidebarMenuItem<'a, Message> {
      fn into_element(self, collapsed: bool) -> Element<'a, Message, Theme> {
          let tooltip = self.collapsed_tooltip(collapsed);
          let is_submenu = !self.children.is_empty();
          // gpui-kit's default_open is one-shot; iced has no persistent state
          // here, so the caller's `open` is authoritative every frame. A
          // submenu never renders open while collapsed.
          let open = self.open && !collapsed;
          let active = self.active;
          let disabled = self.disabled;
          let context_menu = self.context_menu;
          let press = self.pressed_message();
          let toggle = if disabled {
              None
          } else {
              self.on_toggle.clone()
          };

          let mut line = row![].spacing(8).width(Length::Fill).align_y(iced::Alignment::Center);

          if collapsed {
              // Icon only, centred — the label rides along as a tooltip.
              if let Some(icon_name) = self.icon {
                  let cell = container(
                      Icon::new(icon_name)
                          .size(16.0)
                          .into_element(Size::Sm),
                  )
                  .width(Length::Fill)
                  .center_x(Length::Fill);
                  line = line.push(cell);
              }
          } else {
              if let Some(icon_name) = self.icon {
                  line = line.push(Icon::new(icon_name).size(16.0).into_element(Size::Sm));
              }

              let label_style = Size::Md.text();
              let mut label = text(self.label)
                  .size(label_style.size)
                  .line_height(label_style.line_height());
              if active {
                  label = label.font(iced::Font {
                      weight: iced::font::Weight::Medium,
                      ..iced::Font::DEFAULT
                  });
              }

              // gpui-kit's inner `justify_between`: the label cell stretches,
              // pinning the suffix to the trailing edge.
              let mut label_cell =
                  row![].spacing(8).width(Length::Fill).align_y(iced::Alignment::Center);
              label_cell = label_cell.push(container(label).width(Length::Fill));
              if let Some(suffix) = self.suffix {
                  label_cell = label_cell.push(suffix);
              }
              line = line.push(label_cell);

              if is_submenu {
                  let caret = button(
                      Icon::new(caret_icon(open))
                          .size(16.0)
                          .into_element(Size::Sm),
                  )
                  .padding(Padding {
                      top: 4.0,
                      right: 4.0,
                      bottom: 4.0,
                      left: 4.0,
                  })
                  .class(Box::new(move |theme: &Theme, status| {
                      caret_style(theme, status, disabled)
                  }) as button::StyleFn<'a, Theme>)
                  .on_press_maybe(toggle);
                  line = line.push(caret);
              }
          }

          // gpui-kit's row: `p_2` with an inner `h_7` while expanded — the
          // numbers that land on those heights here.
          let mut widget = button(line)
              .width(Length::Fill)
              .padding(Padding {
                  top: if collapsed { 8.0 } else { 4.0 },
                  right: 8.0,
                  bottom: if collapsed { 8.0 } else { 4.0 },
                  left: 8.0,
              })
              .class(Box::new(move |theme: &Theme, status| {
                  item_style(theme, status, active, disabled)
              }) as button::StyleFn<'a, Theme>)
              .on_press_maybe(press);

          let mut element: Element<'a, Message, Theme> = widget.into();

          if let Some(label) = tooltip {
              element = tooltip_at(element, label, TooltipPosition::Right);
          }

          if let Some(message) = context_menu {
              element = MouseArea::new(element).on_right_press(message).into();
          }

          if is_submenu && open {
              let mut items = column![].spacing(4).width(Length::Fill);
              for child in self.children {
                  items = items.push(child.into_element(collapsed));
              }

              // gpui-kit's `border_l_1`: iced's Border is four-sided, so the
              // rule is a one-pixel column with a fill height.
              let edge = container(Space::new())
                  .width(Length::Fixed(1.0))
                  .height(Length::Fill)
                  .class(Box::new(|theme: &Theme| container::Style {
                      background: Some(Background::Color(theme.colors().sidebar_border)),
                      ..container::Style::default()
                  }) as container::StyleFn<'a, Theme>);

              // ml_3.5 pl_2.5 py_0.5 — margin, then the rule with its gap.
              let submenu = container(row![edge, items].spacing(10))
                  .width(Length::Fill)
                  .padding(Padding {
                      top: 2.0,
                      right: 0.0,
                      bottom: 2.0,
                      left: 14.0,
                  });

              return column![element, submenu]
                  .width(Length::Fill)
                  .into();
          }

          element
      }
  }
  ```

  ```rust
  /// A private wrapper that animates its width.
  ///
  /// The shell's own node carries the interpolated width, so the row beside
  /// the sidebar reflows smoothly; the content inside lays out at its target
  /// width and is clipped by a layer — the same split gpui-kit makes between
  /// an animated wrapper and a fixed-width sidebar. At a settled width of
  /// zero the content is skipped entirely (layout, drawing, events,
  /// overlays, focus operations), standing in for gpui-kit's hide timer.
  struct SidebarShell<'a, Message, Renderer = iced::Renderer> {
      content: Element<'a, Message, Theme, Renderer>,
      target_width: f32,
      align_end: bool,
  }

  /// The shell's animation state, kept in the widget tree.
  #[derive(Debug, Clone, Copy, Default)]
  struct ShellState {
      width: crate::motion::SpringState,
      last: Option<Instant>,
      primed: bool,
  }

  fn shell_spring() -> crate::motion::Spring {
      if crate::motion::reduce_motion() {
          crate::motion::Spring::new(Duration::ZERO)
      } else {
          crate::motion::Spring::new(crate::motion::DURATION_NORMAL).with_epsilon(0.05)
      }
  }

  impl ShellState {
      /// The width to lay out this frame, priming on the first one so the
      /// sidebar starts where it belongs instead of sliding in at startup.
      fn current(&mut self, target: f32) -> f32 {
          if !self.primed {
              self.width.set(target);
              self.primed = true;
          }
          self.width.value().max(0.0)
      }

      /// Advances one frame; reports whether another frame is needed.
      fn advance(&mut self, target: f32, elapsed: Duration) -> bool {
          let spring = shell_spring();
          self.width.step(target, spring, elapsed);

          if self.width.is_settled(target, spring) {
              // A spring converges asymptotically: without landing exactly on
              // the target, an offcanvas sidebar would stop a few thousandths
              // short of zero and its content would never be skipped.
              self.width.set(target);
              false
          } else {
              true
          }
      }
  }

  /// Events landing outside the animated clip target nothing: the pointer is
  /// over content that is not on screen.
  fn gate_cursor(cursor: mouse::Cursor, bounds: Rectangle) -> mouse::Cursor {
      match cursor.position() {
          Some(position) if bounds.contains(position) => cursor,
          _ => mouse::Cursor::Unavailable,
      }
  }

  impl<'a, Message, Renderer> SidebarShell<'a, Message, Renderer>
  where
      Message: Clone + 'a,
      Renderer: renderer::Renderer,
  {
      fn new(content: Element<'a, Message, Theme, Renderer>, target_width: f32, align_end: bool) -> Self {
          Self {
              content,
              target_width,
              align_end,
          }
      }

      /// Whether the shell is settled at zero — nothing of the sidebar is on
      /// screen then, so nothing of it may lay out, draw, react or be found.
      fn hidden(tree: &tree::Tree) -> bool {
          let state = tree.state.downcast_ref::<ShellState>();
          !state.primed || state.width.value() <= 0.0
      }
  }

  impl<Message, Renderer> Widget<Message, Theme, Renderer> for SidebarShell<'_, Message, Renderer>
  where
      Message: Clone,
      Renderer: renderer::Renderer,
  {
      fn tag(&self) -> tree::Tag {
          tree::Tag::of::<ShellState>()
      }

      fn state(&self) -> tree::State {
          tree::State::new(ShellState::default())
      }

      fn children(&self) -> Vec<tree::Tree> {
          vec![tree::Tree::new(&self.content)]
      }

      fn diff(&self, tree: &mut tree::Tree) {
          tree.diff_children(std::slice::from_ref(&self.content));
      }

      fn size(&self) -> iced::Size<Length> {
          // The hint tracks the animated width: siblings beside the shell see
          // where it is heading, the node still reports the current frame.
          iced::Size::new(Length::Fixed(self.target_width.max(0.0)), Length::Fill)
      }

      fn layout(
          &mut self,
          tree: &mut tree::Tree,
          renderer: &Renderer,
          limits: &layout::Limits,
      ) -> layout::Node {
          let state = tree.state.downcast_mut::<ShellState>();
          let current = state.current(self.target_width);

          if current <= 0.0 {
              // Offcanvas settled at zero: gpui-kit unmounts behind a timer;
              // iced has no tab order to leave, the width check is enough.
              return layout::Node::new(limits.resolve(
                  Length::Fixed(0.0),
                  Length::Fill,
                  iced::Size::ZERO,
              ));
          }

          let mut content = self
              .content
              .as_widget_mut()
              .layout(&mut tree.children[0], renderer, limits);

          // Children of `with_children` start at (0, 0); `move_to` offsets
          // them relative to this node. Sliding right while shrinking lets a
          // left sidebar disappear past its own right edge — and a negative
          // offset is clipped by the layer anyway.
          let content_width = content.bounds().width;
          content.move_to(iced::Point::new(
              if self.align_end {
                  current - content_width
              } else {
                  0.0
              },
              0.0,
          ));

          layout::Node::with_children(
              iced::Size::new(current, content.bounds().height),
              vec![content],
          )
      }

      fn operate(
          &mut self,
          tree: &mut tree::Tree,
          layout: layout::Layout<'_>,
          renderer: &Renderer,
          operation: &mut dyn Operation,
      ) {
          // A sidebar at width zero must not be reachable by focus traversal.
          if Self::hidden(tree) {
              return;
          }
          if let Some(child_layout) = layout.children().next() {
              self.content.as_widget_mut().operate(
                  &mut tree.children[0],
                  child_layout,
                  renderer,
                  operation,
              );
          }
      }

      fn update(
          &mut self,
          tree: &mut tree::Tree,
          event: &Event,
          layout: layout::Layout<'_>,
          cursor: mouse::Cursor,
          renderer: &Renderer,
          clipboard: &mut dyn Clipboard,
          shell: &mut Shell<'_, Message>,
          viewport: &Rectangle,
      ) {
          let state = tree.state.downcast_mut::<ShellState>();
          let target = self.target_width;
          let _ = state.current(target);

          if let Event::Window(iced::window::Event::RedrawRequested(now)) = event {
              let elapsed = state
                  .last
                  .map_or(Duration::ZERO, |last| now.duration_since(last));
              state.last = Some(*now);

              if state.advance(target, elapsed) {
                  // The node's width changes on this frame, so cached layout
                  // is stale as well as the pixels.
                  shell.invalidate_layout();
                  shell.request_redraw();
              }
          }

          let current = state.width.value().max(0.0);
          drop(state);

          if current <= 0.0 {
              return;
          }

          let Some(child_layout) = layout.children().next() else {
              return;
          };

          // The clip defines what is on screen: anything outside it hovers
          // nothing, so a shrinking sidebar stops reacting on the part of
          // itself that has already slid away.
          let child_cursor = gate_cursor(cursor, layout.bounds());

          self.content.as_widget_mut().update(
              &mut tree.children[0],
              event,
              child_layout,
              child_cursor,
              renderer,
              clipboard,
              shell,
              viewport,
          );
      }

      fn draw(
          &self,
          tree: &tree::Tree,
          renderer: &mut Renderer,
          theme: &Theme,
          style: &renderer::Style,
          layout: layout::Layout<'_>,
          cursor: mouse::Cursor,
          viewport: &Rectangle,
      ) {
          let bounds = layout.bounds();
          if bounds.width <= 0.0 || !bounds.intersects(viewport) {
              return;
          }
          let Some(child_layout) = layout.children().next() else {
              return;
          };

          let child_cursor = gate_cursor(cursor, bounds);
          renderer.with_layer(bounds, |renderer| {
              self.content.as_widget().draw(
                  &tree.children[0],
                  renderer,
                  theme,
                  style,
                  child_layout,
                  child_cursor,
                  viewport,
              );
          });
      }

      fn mouse_interaction(
          &self,
          tree: &tree::Tree,
          layout: layout::Layout<'_>,
          cursor: mouse::Cursor,
          viewport: &Rectangle,
          renderer: &Renderer,
      ) -> mouse::Interaction {
          if Self::hidden(tree) {
              return mouse::Interaction::default();
          }
          let Some(child_layout) = layout.children().next() else {
              return mouse::Interaction::default();
          };

          self.content.as_widget().mouse_interaction(
              &tree.children[0],
              child_layout,
              gate_cursor(cursor, layout.bounds()),
              viewport,
              renderer,
          )
      }

      fn overlay<'b>(
          &'b mut self,
          tree: &'b mut tree::Tree,
          layout: layout::Layout<'b>,
          renderer: &Renderer,
          viewport: &Rectangle,
          translation: iced::Vector,
      ) -> Option<iced::advanced::overlay::Element<'b, Message, Theme, Renderer>> {
          // Tooltips of a hidden sidebar would surface over the window where
          // its content no longer is.
          if Self::hidden(tree) {
              return None;
          }
          let child_layout = layout.children().next()?;

          self.content.as_widget_mut().overlay(
              &mut tree.children[0],
              child_layout,
              renderer,
              viewport,
              translation,
          )
      }
  }
  ```
